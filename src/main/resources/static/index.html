Access Portal Detailed Project Guide Admin Demo Member Self-Service Demo

Member Management

Complete digital registration with multiple identifiers, KYC details, nominee information, and strict financial ledger separation.

Monthly Savings Collections

Idempotent monthly recurring collection generation, duplicate prevention, payment tracking (Paid, Partial, Pending), and instant receipts.

Loan Applications & Approvals

Members submit loan requests online. Admins review, adjust sanction amounts, set interest rates, and auto-generate monthly repayment schedules.

Strict Role Privacy

Normal members can ONLY view their own records and submit loan applications. Admins manage the group securely with comprehensive audit logs.

Multilingual Support

Seamless native interface in English, Marathi (मराठी), and Hindi (हिन्दी) tailored for rural and urban community leaders.

Google Cloud Architecture

Designed specifically for Google Cloud Run, Cloud Firestore, Cloud Storage, and Secret Manager for high availability and security.
